

# Моя шпаргалка по Памяти и Замыканиям

## weak self и guard let
* **[weak self]** — говорим Swift: *"Не держи меня насильно в памяти, если экран закрывают"*.
* **guard let self = self else { return }** — проверяем: *"Я всё ещё живой в памяти? Если да — работаем дальше, если меня уже удалили — ничего не делаем"*.
